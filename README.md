# 🔐 JavaScript Login System

A simple Login System project developed using **HTML, CSS, and JavaScript**. This project allows users to enter their login credentials and validates the information using JavaScript.

## 🌐 Live Demo
[Click Here to View Project](https://zaidy7433.github.io/java-script-login-system-/)

## ✨ Features
- User login functionality.
- Username and password input.
- JavaScript form validation.
- Interactive user experience.
- Simple and clean design.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
